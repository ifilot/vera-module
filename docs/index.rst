VERA Module Documentation
=========================

VERA is a self-contained FPGA video, audio, and storage interface. It provides
two composited graphics layers, hardware sprites, a programmable sound
generator, PCM playback, and an SD-card SPI controller through a compact
parallel register interface.

This guide is for people bringing up a module, writing a bridge or host driver,
or creating software that talks to VERA directly.
