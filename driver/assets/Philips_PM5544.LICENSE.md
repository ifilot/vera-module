# Philips PM5544 asset attribution

`Philips_PM5544.svg` is the Wikimedia Commons file **Philips PM5544.svg** by
ebnz, with the current file page identifying it as an own-work vector image.

- Source: https://commons.wikimedia.org/wiki/File:Philips_PM5544.svg
- Original: https://upload.wikimedia.org/wikipedia/commons/a/aa/Philips_PM5544.svg
- Licence selected for this derivative: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

The following derived files are a 320×240 rasterization, its indexed palette,
an RGB444 VERA preview, and the generated Mega framebuffer header:

- `philips-pm5544-320x240-source.png`
- `philips-pm5544-320x240-indexed.png`
- `philips-pm5544-320x240-vera-rgb444.png`
- `../src/vera_driver/pm5544_image.h`

Changes: rasterized from the SVG to 320×240, mapped without dithering to its
twenty original flat colours, then converted to VERA's 12-bit RGB444 palette.
